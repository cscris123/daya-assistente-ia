# Base de Conhecimento — Python

## Objetivo
Fundamentos de Python relevantes para estudantes de Ciência de Dados.

## Conceitos
- **Variáveis e tipos:** `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict` e `set`.
- **Condicionais:** `if`, `elif` e `else` permitem decisões no código.
- **Laços:** `for` percorre coleções; `while` repete enquanto uma condição for verdadeira.
- **Funções:** agrupam tarefas reutilizáveis e podem receber parâmetros e retornar valores.
- **Listas:** coleções ordenadas de valores.
- **Dicionários:** estruturas de chave-valor.
- **NumPy:** computação numérica e arrays.
- **Pandas:** manipulação e análise de dados tabulares, com `DataFrame` e `Series`.

## Exemplo
```python
idades = [20, 25, 30]
media = sum(idades) / len(idades)
```

## Aprofundamento
Compreensão de listas, iteradores, geradores, decorators, orientação a objetos e otimização.
