# Base de Conhecimento — Inteligência Artificial

## Conceitos
- **Inteligência Artificial:** métodos para sistemas executarem tarefas associadas à inteligência humana.
- **Machine Learning:** subárea que aprende padrões a partir de dados.
- **Deep Learning:** Machine Learning baseado principalmente em redes neurais com múltiplas camadas.
- **IA Generativa:** modelos capazes de gerar texto, imagem, áudio, código e outros conteúdos.
- **Modelos de linguagem:** trabalham com sequências de texto e geram respostas condicionadas ao contexto.
- **Prompt:** instrução usada para orientar um modelo.
- **System prompt:** define regras, objetivos, comportamento e restrições gerais.
- **Alucinação:** resposta aparentemente plausível, mas incorreta, inventada ou não sustentada pela base.
- **Grounding:** fundamentação das respostas em fontes ou dados fornecidos ao sistema.

## Boas práticas
Fornecer contexto, estabelecer limites, testar cenários e instruir o agente a reconhecer quando não possui informação suficiente.

## Exemplo
A Daya deve usar a base de conhecimento para responder perguntas de Ciência de Dados e informar quando a base não cobre determinado assunto.
