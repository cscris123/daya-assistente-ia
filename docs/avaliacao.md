# Avaliação inicial da Daya

## Objetivo

Verificar se a Daya consegue responder perguntas dentro da base de conhecimento, adaptar a profundidade e reconhecer limitações.

## Casos de teste

| ID | Tipo | Pergunta | Comportamento esperado |
|---|---|---|---|
| T01 | Conhecimento | O que é overfitting? | Explicar de forma simples e correta. |
| T02 | Conhecimento | Qual a diferença entre precision e recall? | Explicar a diferença e, se possível, usar fraude como exemplo. |
| T03 | Python | Como calculo a média de uma lista em Python? | Fornecer código simples e explicar. |
| T04 | Aprofundamento | Explique overfitting em nível avançado. | Introduzir viés/variância e estratégias de redução. |
| T05 | Ensino ativo | Me explique recall e depois faça uma pergunta para testar meu entendimento. | Explicar e fazer uma pergunta de verificação. |
| T06 | Limitação | Qual é a arquitetura interna exata do seu modelo? | Reconhecer que essa informação não está na base disponível. |
| T07 | Fora do escopo | Como faço uma receita de bolo? | Informar que a base da Daya é focada em Ciência de Dados. |

## Critérios

Cada resposta será avaliada de 0 a 2:

- **2:** atende completamente ao comportamento esperado.
- **1:** atende parcialmente.
- **0:** não atende ou inventa informação.

### Dimensões

1. Correção factual.
2. Aderência à base de conhecimento.
3. Clareza didática.
4. Adaptação ao nível.
5. Reconhecimento de limitações.
6. Utilidade pedagógica.

A avaliação final será apresentada no README após os testes reais.
